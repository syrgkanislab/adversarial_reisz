# adversarial_reisz
Adversarial estimation of Riesz representers

To reproduce the results of the paper:
(1) Clone this repository.
(2) Use the requirements.txt file to create a virtual environment (see README.txt).
(3) Create a directory named "gcv_results" in the working directory (i.e., where the repository files are located)
(4) Run Results_GCV.py, perhaps on a HPC cluster using a batch file.

Warning: The leftover files (not used for the paper) AdversarialReisz.ipynb and 401k.ipynb do not have a fixed seed for advnnet.
